# fill-log — تحليل سجل التعبئة

قاعدة المالك: «عالج أي مشكلة بالمنطق» — لا تنتظر لقطات شاشة إن كان السجل والكود يفسّران المشكلة.

1. **احصل على السجل** (أحد هذه):
   - اطلب من المالك: لوحة الإدارة ← الطلبات ← «سجل التعبئة» تحت المعلم ← **«نسخ للتحليل»** ثم يلصقه في المحادثة.
   - إن كانت لديك قراءة من القاعدة: `select admin_fill_log(<رقم الطلب>);` أو
     `select * from fill_log where user_id = (select user_id from ext_requests where id = <رقم الطلب>) order by at;`
2. احفظه في ملف مؤقت وشغّل:
   ```bash
   node tools/fill-log.mjs /tmp/log.json        # ملخص + المشاكل
   node tools/fill-log.mjs /tmp/log.json --run <run_id>   # تشغيلة بكل أسطرها
   ```
3. لكل `✗` اربطه بالكود: التكرار ← حفظ لم يُؤكَّد (`unconfirmed`) ثم أُعيد، أو قراءة قائمة نور؛ الترتيب والتواريخ ← `assignDates` في `extension/semester.js`؛
   «بلا درس نور» ← المطابقة (`alignGroups`، `extension/match.js`). أعد إنتاج المشكلة على نور المحاكى (`tests/noor-mock`) قبل الإصلاح.
4. لخّص للمالك بلغة هادئة: ما حدث، هل في نور تكرار يحتاج حذفًا يدويًا، وما الإصلاح. إصلاح الكود والإصدار عبر مهارة `release`.
