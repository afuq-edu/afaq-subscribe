# doctor — فحص سريع

1. شغّل من جذر المستودع:
   ```bash
   node tools/doctor.mjs
   ```
2. إن ظهر `DOCTOR FAILED` أصلح كل سطر `✗` قبل أي شيء آخر:
   - **صياغة**: الملف والسطر مذكوران.
   - **manifest يشير إلى ملف غير موجود**: ملف حُذف أو أُعيدت تسميته دون تعديل `extension/manifest.json`.
   - **دالة RPC بلا تعريف**: الموقع أو الإضافة تنادي دالة ليست في `site/supabase/*.sql` — أضف ملف SQL أو صحّح الاسم. (تطبيق SQL على القاعدة الحية قرار المالك.)
   - **إعدادات مختلفة**: `site/config.js` و`extension/afaq-config.js` يجب أن يحملا الرابط والمفتاح نفسيهما.
3. التحذيرات (`!`) لا تُفشل الفحص؛ اذكرها في الملخص.
4. لخّص بالعربية في سطر أو سطرين: سطر الخلاصة الأخير وما أصلحته.

نفس الفحص يعمل تلقائيًا على كل طلب دمج (`.github/workflows/checks.yml`) مع `tests/db.test.mjs`.
