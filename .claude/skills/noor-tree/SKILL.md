# noor-tree — شجرات نور الحقيقية

قاعدة المالك: «اهم شي تطور الاداه بعد كل شجرة حقيقيه» — كل مادة تُختبر على شجرتها الحقيقية قبل كل إصدار.

1. **احصل على الشجرات:** المالك يضغط في لوحة الإدارة ← «شجرات نور» ← **«نسخ كل الشجرات للاختبارات»** ويلصقها، أو بقراءة من القاعدة:
   `select id, package_id, term, term_text, seen, last_at, ver, lessons from noor_trees order by last_at desc;`
2. **اعرض ثم اكتب:**
   ```bash
   node tools/noor-tree.mjs /tmp/trees.json            # الجديد والمتغيّر
   node tools/noor-tree.mjs /tmp/trees.json --write    # (--alias إن لم تكن للفترة الأخرى شجرة)
   ```
3. **اختبر** بالأمرين اللذين تطبعهما الأداة: `align.mjs` (كل حصة لها درس، وكل درس نور له حصة) ثم `matrix.mjs` مع `REAL_TREES` على المواد الجديدة.
4. **ما لا يُطابَق:**
   - اختلاف تسمية يمكن للأداة فهمه ← أصلحه في `alignGroups` (`extension/semester.js`) — إصدار جديد عبر مهارة `release`.
   - درس في نور بلا محتوى في ملف التحضير (أو العكس) ← سجّله في `_gaps` في `trees.json` واذكر للمالك أنه يحتاج محتوى تحضير لا كودًا.
5. `node tools/doctor.mjs` ثم ادمج.
