# prep-check — فحص ملفات التحضير

1. افحص ما تغيّر (أو كل الباقات بلا وسائط):
   ```bash
   node tools/prep-check.mjs /mnt/project-files/afaq-platform/preps/<الملف أو المجلد أو zip> -v
   ```
2. كل `✗` يجب إصلاحه قبل الرفع (تاريخ جمعة/سبت، معرّف مكرر، حقل أساسي فارغ، رابط نشاط بلا ملف في `site/games`، زمن حصة لا يطابق الفترة).
   التحذيرات تُذكر للمالك ولا تمنع الرفع (حصص بلا وحدة في الرياضيات الثامن طبيعية).
3. إن عدّلت ملفات التحضير: جرّب الباقات المعدّلة على نور المحاكى `node tests/noor-mock/matrix.mjs --only <id>-t1 --jobs 2`،
   وعلى شجرتها الحقيقية إن كانت لها شجرة: `node tests/noor-mock/real-trees/align.mjs`.
4. سلّم zip التحاضير في `/mnt/project-files/afaq-platform/preps/` واذكر أن المالك يرفعه من لوحة الإدارة ← «الباقات» ← «رفع تحاضير كثيرة دفعة واحدة».
