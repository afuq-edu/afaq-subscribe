# graphify — خريطة المشروع

تصنع صفحة HTML واحدة مستقلة (RTL، فاتح وداكن، تعمل على الهاتف) فيها: بطاقات الأرقام الرئيسية، حجم كل مجلد رئيسي بشريط ملوّن (أخضر تحت 70%، برتقالي حتى 90%، أحمر فوقه؛ `site/` محسوب من حد GitHub Pages ‏1 GB والباقي من نسبته إلى الحجم الكلي)، شجرة البنية مبنية على جدول الأقسام في `README.md`، جدول السكربتات وأول سطر من شرح كل منها، أنشطة الدروس حسب المادة، أنواع الملفات، أكبر الملفات، وقائمة «ملاحظات».

## الخطوات

1. **حدّث المستودع دون تعديل أي ملف:**
   ```bash
   git fetch origin
   git merge --ff-only @{u}
   ```
   إن فشل `--ff-only` (فرع متباعد أو تعديلات محلية) فلا تدمج ولا تعدّل شيئًا: شغّل الأداة على الحالة الحالية واذكر ذلك في الملخص.

2. **شغّل الأداة واكتب الصفحة في مجلد مؤقت خارج المستودع:**
   ```bash
   OUT="$(mktemp -d)/project-map.html"
   python3 tools/graphify.py -o "$OUT"
   ```
   الأداة ترفض الكتابة داخل المستودع. بلا `-o` تنشئ مجلدًا مؤقتًا وتطبع مسار الصفحة.

3. **أرسل الصفحة للمستخدم** كملف مرفق في ردك. إن كانت بيئتك لا ترفق إلا من مجلد مشترك (مثل `/mnt/project-files/`) فانسخها إلى مجلد فرعي فيه (`graphify/`) وأرفقها من هناك. **لا تنشر الصفحة (Artifact أو رابط عام) ولا ترفعها إلى المستودع إلا إذا طلب المستخدم ذلك.**

4. **لخّص بالعربية في سطور قليلة** (من بطاقات الصفحة وقسم «ملاحظات»):
   - الأرقام الرئيسية: الملفات، المجلدات، الحجم الكلي، حجم الموقع المنشور ونسبته من حد GitHub Pages، إصدار «حاضر»، أنشطة الدروس والباقات والمواد، شجرات نور الحقيقية.
   - أي مجلد أو ملف كبير أو قريب من حد المساحة (شريط برتقالي أو أحمر، ملف فوق 50 MB، المستودع مع تاريخه قرب 1 GB).
   - أي شيء ناقص أو غير مرتب: مجلدات لا يصفها `README.md`، مسارات في الدليل غير موجودة، سكربتات بلا سطر شرح، ملفات فارغة، باقات أنشطة بلا `index.json`.

## ملاحظات للصيانة

- الملفات المحسوبة هي ملفات git (`git ls-files`)، فالملفات المتجاهلة و`node_modules` لا تدخل.
- الأعداد الخاصة بالمشروع تُكتشف من بنيته: `extension/manifest.json` (الإصدار)، `site/games/<باقة>/<رقم>.json` (أنشطة الدروس واسم المادة من أول درس)، `tests/noor-mock/real-trees/trees.json` (شجرات نور)، `site/supabase/*.sql`، صفحات `site/*.html`.
- عند إضافة قسم جديد للمشروع أضف له صفًا في جدول الأقسام في `README.md` فيظهر في الشجرة باسمه ووصفه.
