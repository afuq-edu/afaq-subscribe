# versions — حالة النسخ

1. شغّل `node tools/versions.mjs`. إن لم تصل الحاوية إلى الإنترنت (`تعذّر`):
   - شغّل سير العمل «حالة نسخ حاضر» (`.github/workflows/versions.yml`، workflow_dispatch) واقرأ ملخصه، أو
   - افتح صفحة المتجر `https://chromewebstore.google.com/detail/dppamelcpolikjnkfajfpgpfbomklbha` بأداة جلب الويب واقرأ «Version».
2. اتبع «ما يجب فعله» الذي تطبعه الأداة. **أهم قاعدة:** لا تُرفع `min_ext_version` إلا بعد أن يعرض المتجر النسخة الجديدة، وبطلب المالك فقط
   (تُغيَّر في لوحة الإدارة ← الإعدادات). إن كانت أعلى من نسخة المتجر فلا أحد يستطيع التعبئة — نبّه المالك فورًا.
3. لخّص في سطرين: النسخ الأربع وأي إجراء مطلوب من المالك.
