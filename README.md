# منصة أفق التعليمية — دليل النشر

الحزمة ثلاثة أجزاء تعمل معًا:

| المجلد | ما هو | أين يعمل |
|---|---|---|
| `site/` | موقع المعلمين ولوحة الإدارة | استضافة مجانية (Netlify) |
| `site/supabase/schema.sql` | قاعدة البيانات وقواعد الصلاحيات | Supabase |
| `extension/` | إضافة «حاضر» نسخة الخدمة | متجر كروم |
| `tests/` | اختبارات (اختيارية) | حاسوبك |

يستغرق الإعداد نحو ساعة، مرة واحدة.

> **جديد في هذه النسخة: الاشتراك الفصلي والسنوي.**
> - **فصلي:** فصل دراسي واحد، ينتهي بنهايته (كما كان).
> - **سنوي:** الفصلان الأول والثاني من العام الدراسي برمز واحد. يعمل في الفصل الأول، وعندما تضيف الفصل الثاني في «الفصول» يُضاف إلى كل المشتركين السنويين تلقائيًا دون رمز جديد، وينتهي بنهاية الفصل الثاني.
> - سعر الباقة لكل نوع يُكتب في لوحة الإدارة ← الإعدادات (الافتراضي ٥ ر.ع. فصلي و٩ ر.ع. سنوي)، ويظهر للمعلم في صفحة الباقات مع المجموع، وفي رسالة الطلب على واتساب.
> - من لوحة الإدارة ← المعلمون يمكنك **إنشاء اشتراك مباشرة** لمعلم مسجّل (فصلي أو سنوي) دون رمز تفعيل.
>
> **إن كنت نفّذت `schema.sql` من قبل:** نفّذ الملف الجديد مرة أخرى في SQL Editor. لا يمسح شيئًا، ويضيف الاشتراك السنوي والأسعار.

---

## ١. قاعدة البيانات (Supabase)

1. أنشئ حسابًا في supabase.com، ثم **New project**. اختر كلمة مرور قوية لقاعدة البيانات واحفظها.
2. افتح **SQL Editor ← New query**، والصق محتوى `site/supabase/schema.sql` كاملًا، ثم **Run**. يجب أن تظهر «Success».
3. من **Project Settings ← API** انسخ قيمتين:
   - **Project URL** (مثل `https://abcd.supabase.co`)
   - مفتاح **anon public**

   > لا تضع مفتاح **service_role** في الموقع أو الإضافة أبدًا. مفتاح anon عام بطبيعته، والحماية في قواعد الصلاحيات.

4. من **Authentication ← URL Configuration**: اكتب رابط موقعك في **Site URL** (بعد الخطوة ٢)، وأضفه في **Redirect URLs**.
5. تأكيد البريد: من **Authentication ← Providers ← Email** يمكنك إبقاء **Confirm email** مفعّلًا (أكثر أمانًا) أو إيقافه (تسجيل أسرع).

## ٢. الموقع (Netlify)

1. افتح `site/config.js` واكتب فيه `SUPABASE_URL` و`SUPABASE_ANON_KEY`. اترك `EXTENSION_ID` الآن.
2. ادخل app.netlify.com ← **Add new site ← Deploy manually**، واسحب مجلد `site` كاملًا إلى الصفحة.
3. يعطيك Netlify رابطًا مثل `https://afaq-xxxx.netlify.app`. يمكنك تغييره من **Site configuration ← Change site name**، أو ربط نطاقك الخاص.
4. ارجع إلى Supabase (الخطوة ١-٤) واكتب هذا الرابط.

## ٣. اجعل نفسك مديرًا

1. افتح موقعك وأنشئ حسابًا لنفسك.
2. في Supabase ← **SQL Editor** نفّذ (ضع بريدك):

   ```sql
   update public.profiles set is_admin = true
   where id = (select id from auth.users where email = 'بريدك@example.com');
   ```

3. افتح `رابط-موقعك/admin.html` وسجّل الدخول.

## ٤. الإضافة (متجر كروم)

1. افتح `extension/afaq-config.js` واكتب فيه القيم نفسها: `SUPABASE_URL` و`SUPABASE_ANON_KEY`، ورابط موقعك في `SITE_URL`.
2. افتح `extension/manifest.json`، وفي `externally_connectable` استبدل `https://YOUR-SITE.netlify.app/*` برابط موقعك، واحذف سطر `http://localhost/*`. هذا يضمن ألا يكلّم الإضافةَ إلا موقعك.
3. **للتجربة قبل المتجر:** `chrome://extensions` ← فعّل «وضع المطوّر» ← «تحميل إضافة غير مضغوطة» ← اختر مجلد `extension`. انسخ **المعرّف** الظاهر في بطاقتها إلى `EXTENSION_ID` في `site/config.js`، وأعد نشر الموقع.
4. **النشر:** أنشئ حساب مطوّر في متجر كروم (Chrome Web Store Developer Dashboard، برسوم تسجيل لمرة واحدة)، ثم اضغط مجلد `extension` في ملف zip وارفعه.
   - **Visibility:** «Unlisted» (لا تظهر في البحث، تُثبَّت بالرابط فقط) أو «Public».
   - **Privacy policy:** `رابط-موقعك/privacy.html`.
   - **تبرير الصلاحيات:** الإضافة تعبّئ نموذج «إضافة تحضير» في `lms.moe.gov.om` وتجلب محتوى الحصة من خادم المنصة.
5. بعد قبولها: انسخ **معرّف الإضافة في المتجر** (32 حرفًا في رابط صفحتها) إلى `EXTENSION_ID` في `site/config.js` وأعد نشر الموقع، واكتب رابط صفحتها في المتجر في لوحة الإدارة ← الإعدادات.

> المعلم لا يحصل على أي ملف: يثبّت الإضافة من المتجر بضغطة، والإضافة فارغة. المواد تصلها من اشتراكه فقط، ومحتوى كل حصة يُجلب لحظة تعبئتها ولا يُخزَّن فيها.

## ٥. التشغيل كل فصل

**من لوحة الإدارة:**

1. **الفصول:** أضف الفصل بتاريخ بدايته ونهايته. الاشتراكات تنتهي تلقائيًا بنهاية يوم «النهاية» بتوقيت مسقط، وتعديل التاريخ يسري على كل اشتراكات الفصل.
2. **الباقات والتحاضير:** أضف لكل مادة وصف باقة (الإنجليزي للخامس والإنجليزي للسادس باقتان). ثم ارفع لكل فصل ملف المادة:
   - في نسختك الشخصية من «حاضر» (الإصدار 3.10، وفيها المكتبة المحلية): صفحة المادة ← **تصدير ملف**.
   - في لوحة الإدارة: **ارفع** بجوار الفصل. الرفع يستبدل المحتوى السابق، ويصل التحديث للمعلمين في المزامنة التالية.
3. **الإعدادات:** سعر الباقة الفصلي والسنوي، ورقم واتساب المنصة، ورابط الإضافة في المتجر، والحد اليومي (افتراضيًا ٢٠٠ حصة مختلفة في ٢٤ ساعة)، وعدد الأجهزة (افتراضيًا ٢).

**عند وصول طلب على واتساب:** الطلب يصلك جاهزًا بالاسم والهاتف والبريد ونوع الاشتراك (فصلي أو سنوي) والباقات والمجموع. بعد استلام المبلغ، من **رموز التفعيل** اكتب الاسم كما في الطلب، واختر **نوع الاشتراك**، ثم الفصل (للفصلي) أو العام الدراسي (للسنوي)، والباقات، ثم **أصدر الرمز** ← **أرسلها عبر واتساب** (رسالة جاهزة فيها الرمز ومدته ورابط التفعيل).

**أو مباشرة دون رمز:** إن كان المعلم مسجّلًا في الموقع، افتح **المعلمون** ← «أضف اشتراكًا» بجوار اسمه، واختر النوع والمدة والباقات ← **أنشئ الاشتراك**. يُفعَّل فورًا.

**ما يفعله المعلم:** يسجّل في الموقع، ويطلب الرمز، ويفعّله من حسابه، ويثبّت الإضافة. عند فتحه الموقع تُربط الإضافة بحسابه تلقائيًا، ثم يفتح نور ← «حاضر» ← «تحضير فصل كامل».

## ٦. الحماية المبنية

- **الرمز باسم المعلم:** لا يعمل إلا لحساب يطابق اسمه، مع تسامح في الكتابة: الهمزات، و«بن»، و«عبد الله» و«عبدالله»، و«ال». ويُستعمل مرة واحدة.
- **الاسم يُقفل بعد أول تفعيل.** تعديله من لوحة الإدارة ← المعلمون ← «تعديل الاسم».
- **المحتوى لا يقرؤه أحد مباشرة.** يُسلَّم حصةً حصة للمشترك الفعّال فقط، مع حد يومي، وعلامة مائية خفية تحمل رمز المعلم.
- **الأجهزة:** جهازان لكل حساب افتراضيًا، وربط ثالث يفصل الأقدم. ومن لوحة الإدارة «فصل الأجهزة» عند الاشتباه بمشاركة الحساب.
- **التخمين:** بعد ١٠ محاولات تفعيل خاطئة في ساعة يتوقف الحساب مؤقتًا.
- **الانتهاء:** في نهاية الفصل يتوقف المحتوى في الخادم فورًا، وتحذف الإضافة المادة في مزامنتها التالية (كل ٦ ساعات وعند فتح كروم).

## ٧. الاختبارات (اختيارية)

```bash
cd tests
npm install
node db.test.mjs    # قاعدة البيانات والصلاحيات على PostgreSQL حقيقي
node e2e.test.mjs   # الدورة كاملة: المدير ← المعلم ← الرمز ← الإضافة ← نهاية الفصل ← الاشتراك السنوي
```

## قبل الإطلاق

- **منصة نور:** اسأل وزارة التربية والتعليم عن موقفها من التعبئة الآلية، ويفضّل أن تحصل على موافقة مكتوبة.
- **المحتوى:** تأكد من حقك في بيع التحاضير المبنية على أدلة المعلم الوزارية.
- **الخصوصية:** راجع صفحة `privacy.html` مع مختص في قانون حماية البيانات الشخصية في عُمان.
